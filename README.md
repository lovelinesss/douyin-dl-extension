# 抖音下载助手（浏览器扩展版）

由油猴脚本 dy-dl.user.js 改造而来，功能一致，但下载改由浏览器下载管理器接管。

> ⚠️ **重要：请用 Edge 浏览器，不要用 Chrome**
>
> 你这台机器的 Chrome 被策略禁用了扩展程序（扩展管理页显示
> 「此设置由您的管理员管理」「您的家长已停用扩展程序权限」），
> 在 Chrome 里装了也不会生效。Edge 没有这个限制，实测可正常加载。

## 一、安装步骤（Edge）

1. 打开 Edge，地址栏输入 `edge://extensions` 后回车
2. 打开左侧或下方的 **开发人员模式** 开关
3. 点击 **解压缩扩展**（或「加载解压缩的扩展」）
4. 在弹出的文件夹选择框里，选中这个文件夹：

   ```
   C:\Users\User\Desktop\douyin-dl-extension
   ```

5. 列表中出现「抖音下载助手」即安装成功
6. **打开抖音网页版，按 F5 刷新一次页面**（不刷新脚本不会注入）

建议固定到工具栏：点击工具栏拼图图标 → 找到「抖音下载助手」→ 点图钉。

## 二、文件存到哪了

**在 `D:\Downloads\douyin\`（D 盘，不是 C 盘的「下载」文件夹）。**

抖音和小红书目前共用这个子目录，想分开的话改脚本设置里的「保存子目录」即可。

不确定有没有下成功时，看**笔记右上角的浮窗**：

- `下载无水印 45%  12.0MB / 26.5MB` —— 正在下，数字会跳
- `下载完成 · 无水印` + 一行完整路径 —— 下好了，按路径找文件
- `下载完成 · 带水印` —— 干净档全失败，只能给你带水印的
- `下载失败` —— 没成功

进度是真的：下载请求发下去以后会一直盯到 Chrome 报告落盘为止，不再像以前那样一提交就说「完成」。

### 命名规则（小红书和抖音一致）

```
昵称_发布日期_赞数_评数_收数_标题.mp4
例：抓马刘铁柱_260823_赞41000_评1907_收2539_难怪中国人说话要有啊啊啊4个声调.mp4
```

- 日期是**发布日期**（YYMMDD），不是下载当天
- 计数一律是纯数字：`4.1万` 会转成 `41000`，和抖音一样
- 小红书标题里的 `[话题]` 占位符会去掉
- 数据没加载完的笔记**不会下载**（宁可不出文件，也不给你一个 `_赞0_评0_收0_undefined` 的名字）；
  遇到按钮不出现时刷新一下页面即可

## 三、使用

### 抖音

- 在 douyin.com 上照常使用，视频/图集上会出现下载按钮，快捷键 `m` 下载当前媒体

### 小红书

- 打开任意**笔记详情页**，笔记**左上角**会出现红色「下载笔记」按钮，快捷键同样是 `m`
- 图集会按顺序下载全部图片（文件名自动加 `_1` `_2`），视频笔记下载视频
- **视频默认下的是无水印版**：小红书只在水印档（内部编号 259，画面右下角带「小红书」和作者名）上烧水印，
  其余档位（108/109/261/301/309/3050/3051）都是干净的，脚本会自动避开 259，按清晰度从高到低挑
- 图片走 `ci.xiaohongshu.com` 原图，直接是 jpg（网页上默认给的是 webp 转码图，
  把地址尾缀 webp 改成 jpg 会被 CDN 挡掉返回 403，所以不能那么改）
- 文件名沿用同一套模板配置
- 按钮文案即状态：`下载无水印` → `完成`；万一所有无水印档都失败会显示 `无水印失败` 再兜底带水印档

### 通用

- 点击工具栏图标打开面板，可看下载队列、设置保存子目录和同时下载数量

改配置：抖音页面上的脚本设置面板 → 下载器 → 类型选「下载管理器（推荐）」

## 四、验证是否生效

按 **F12** → **Console（控制台）** 标签页，正常会看到两行：

```
[dy-dl]脚本已注入
[dy-dl]已启动
```

两行都在说明脚本跑起来了。只有第一行或都没有，说明没生效。

## 五、相比油猴脚本的改进

| 项目 | 油猴脚本 | 本扩展 |
|---|---|---|
| 下载方式 | 先读进内存成 blob 再触发下载 | 交给 chrome.downloads，不占内存 |
| 大视频 | 容易卡、容易失败 | 支持断点续传 |
| 保存位置 | 只能进默认下载目录 | 支持子目录 |
| 批量下载 | 串行且易中断 | 队列调度，可设并发数 |
| 状态查看 | 无 | 工具栏面板实时看进度 |

## 六、已知限制

- **图片转码/压缩**需要转成 blob 处理，开启后会自动回退到原来的浏览器下载流程
- 外部下载器（IDM / aria2 等）走扩展后台转发跨域请求，遇到新 CDN 域名可能要往 manifest 的 host_permissions 里补
- 需要 Edge / Chrome 111+（用到了 MAIN world 注入）

## 七、文件说明

```
manifest.json        扩展配置
background.js        后台服务：下载队列、状态追踪、跨域转发
content-bridge.js    消息桥（ISOLATED world）
content-main.js      主脚本，原有逻辑 + 扩展下载（MAIN world）
popup.html / js      工具栏面板
```
